## Define the quantities separately

Let `A(i,j)` indicate accepted final coassignment, `C(i,j)` actual candidate
exposure during the frozen pipeline, and `Y(i,j)` the blinded reference judgment
that both full reports have one clear focal event and describe that same event.
Related but different events are not matches. The existing generic focal-event
definition, including disclosure versus underlying incident, remains unchanged.
Reference uncertainty is distinct from a substantive finding of multiple events.

| Quantity | Numerator / denominator and unit |
| --- | --- |
| **Primary pair precision** | True same-event pairs coassigned / all coassigned pairs |
| **Primary pair recall within the selected corpus** | True same-event pairs coassigned / all true same-event pairs in the 6,691-input frame |
| Candidate recall | True pairs exposed as candidates / all true pairs in that frame |
| Accepted-join precision | Correct accepted incoming-article-to-target operations / accepted join operations; inspect the full frozen target revision and incoming article |
| Dossier coherence | Final non-singleton dossiers whose entire membership has one common clear focal event / all final non-singleton dossiers; dossier-weighted, not pair-weighted |
| Processing/reference coverage | Selected, attempted, mechanically valid, substantively resolved, uncertain and unavailable counts and their population weights |

`C` includes seed pairs and incoming-article-to-each-member relations in every
candidate dossier actually presented for assignment/recovery. Mere vector score
availability does not count as exposure. Preserve a missing candidate log as a
coverage defect and give unknown `C` a separate stratum; it is never `C=0`.
Pair precision/recall still use the complete `A` frame, while candidate recall
must bound these unknown exposures or remain unavailable. Do not assume `A` is a subset of `C`: joint group construction
can create coassigned pairs that were not individual candidate comparisons.

## Estimation, finite-population bounds and stopping

Primary estimates use the frozen stratum populations. For a completely resolved
binary stratum, the estimated positive total is `N_h * positive_h / n_h`.
Sum totals in the relevant `(A,C)` cells before forming precision/recall ratios.
Do not compute an unweighted percentage from the enriched sample. A complete-case
ratio can be shown as a conditional diagnostic but is not the primary estimate
when unknown reference labels remain.

Use independently reviewed **finite-population hypergeometric interval
inversion** for each stratum's unknown positive total. With `p` resolved positive,
`q` unresolved and fixed selected size `n`, use the lower bound obtained from
`p` successes and the upper bound from `p+q` successes, retaining all `n` selected
units. This gives worst-case treatment of unresolved labels before population
projection. It is valid under the frozen random selection and fixed reference
target, not a claim that model judgment equals objective truth. Completely
unobserved strata retain `[0,N_h]`; censused but uncertain strata retain their
observed ambiguity interval.

For simultaneous coverage over all strata and all three looks, allocate tail
error `0.05 / (2 * H * 3)`, where `H` is the number of nonempty primary strata.
Construct joint bounds on all stratum totals, then map that same joint region
to both primary ratios. This avoids multiplying marginal 95% intervals or using
ordinary repeated 95% checks. No extra factor for the two ratios is needed when
both are projections of the same simultaneous total-count region. Candidate
recall can also use this region. For final pair recall, a conservative bound is
`TP_lower/(TP_lower+FN_upper)` to `TP_upper/(TP_upper+FN_lower)`, with zero-denominator
cases explicitly undefined. Precision divides its true-pair total bounds by
the known count of predicted pairs. Do not hide a very wide interval behind the
point estimate. Bounds may be conservative; a narrower estimator must be specified
and checked prospectively, not selected because these bounds disappoint.

Candidate recall uses that same simultaneous region without another error-budget
allocation. Sum positive-count bounds into `E` (known exposed), `N` (known
unexposed) and `U` (exposure unknown). Its conservative lower endpoint is
`E_lower / (E_lower + N_upper + U_upper)` and upper endpoint is
`(E_upper + U_upper) / (E_upper + U_upper + N_lower)`: unknown-exposure positives
can all be missed or all be retrieved. Retain undefined/possibly-zero denominator
states. Do not publish a single candidate-recall estimate while the upper bound
permits positive mass in exposure-unknown strata. These are conditional
model-reference bounds, not evidence that every event was found. Candidate recall
is a descriptive additional projection, not an extra statistical look or a new
primary stopping target.

At the three declared cumulative looks, stop for achieved precision only if the
primary precision interval has full width **at most 0.06 (±3 percentage points)**
and primary recall has full width **at most 0.10 (±5 points)**, including all
unknown-label bounds. Report the actual endpoints and midpoint rather than an
asymmetric interval as an unjustified symmetric claim. A narrow interval is a
measurement target, not a minimum acceptable accuracy: poor but precise results
are reported as poor. No generic "statistically significant" verdict is planned.

Stop when authorized resources are exhausted, a transport/identity safeguard
fails, or the third look finishes. If either width target remains unmet, the
outcome is **precision/recall not established to the requested resolution**.
Do not raise limits, reroll cases, lower confidence or ignore tail strata. The
existing 50 retained/50 retrieved-nonjoined final audit cannot replace this design.

Rare positives in the never-retrieved tail may dominate recall uncertainty.
For illustration only, zero positives in 1,000 uniformly sampled pairs from a
22,381,395-pair frame still permits roughly 67,000 positives at a one-sided 95%
finite-population bound; the simultaneous bound is wider. Thus even several
thousand negative reviews may not establish ±5-point recall. The preparation
report must show this feasibility risk, not promise that the third look suffices.

Direct pair SRS gives finite-frame design-based inference conditional on fixed
reference labels. It does not make articles from one event independent event
replicates. Report shared articles/dossiers, effective weighted sample sizes and
distinct reference-event counts where resolvable. For secondary dossier sampling,
use the actual cluster/two-stage design for variance; never count every within-group
pair as an independent sampled dossier. Publication beyond this fixed corpus
requires additional representativeness assumptions and separate evaluation.

## Optional event-centric and screening work

Binette et al. propose sampling records and resolving their complete true entity
clusters, enabling weighted estimates of several clustering metrics. This can
reduce sparse-pair labeling effort **when complete reference clusters are actually
available**. It does not justify treating a bounded search result as a complete
event family. [Primary paper](https://arxiv.org/abs/2404.05622)

The authors' ER-Evaluation estimators take complete reference clusters, sampling
weights and the full predicted population; subsetting predictions to a convenient
benchmark changes the quantity. We may later use them for independently resolved
event families, with matching inclusion probabilities and an explicitly registered
design. No package output will certify completeness of our reference search.
[Author documentation](https://er-evaluation.readthedocs.io/en/latest/er_evaluation.estimators.html)

A supplementary random-anchor investigation may search vectors, words, characters,
provider IDs, languages and long follow-ups, plus random residual articles. Record
every searched and unsearched region. Unless all remaining possible members are
resolved or bounded by the probability design, report conditional search coverage,
not exhaustive recall. Twelve earlier selected withheld hypotheses and the adaptive
three-group pilot are useful diagnostics, not a replacement reference census.

Screening accuracy is an **optional separately registered secondary extension**:
sample the original keep/exclude/review/unknown input strata with known probabilities,
then judge cybercrime, single-event focus and Netherlands nexus separately. Preserve
unavailable/sealed sources as missing. This would estimate article-level screening
recall within the stored screenable frame, not capture of all Dutch events/news.
It is not required before the requested clustering validation starts. Do not
multiply article screening recall and pair recall into a misleading combined score.
