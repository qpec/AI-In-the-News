This is an exploratory expansion of the predictor family, not a relaxation of quality requirements or a new model budget.

It revalidates every original source-bound judgment and preserves all 54 references, uncertain labels and original n/N weights. Publication metadata never establishes event identity or event date.

Diagnostic settings require eight selected same references and rank weighted precision, weighted coverage and stricter thresholds; they are not automatically eligible.

Resume reuses the exact recorded development grid, candidate and manifest without retuning. The original shared holdout-opening registry spans all parent/child methods. If fewer than twenty predicted links are available, report insufficient support without spending model calls. Missing features remain null and block validation.
